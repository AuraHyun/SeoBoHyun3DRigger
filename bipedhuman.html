Biped Woman Rigging

3ds Max Biped Unreal Engine

Overview

3ds Max Biped를 이용해서 여자 리깅을 했습니다. 이후에 언리얼로 옮겨서 모핑을 넣어봤습니다. 특수 리깅 부위 위주로 영상을 만들었습니다.

Tool Info

Software
3ds Max, Unreal Engine
Rig Type
Biped

Rig Details

01

Hair

Path Constraint와 Offset과 Skin Curve와 Position Constraint를 둬서 자연스럽게 컨트롤러의 움직임에 머리카락 세부 컨트롤러가 따라가도록 리깅했습니다.

02

Joint

Groin, Butt, Knee, Elbow, Shoulder, Clavicle에 중간본과 Twist Bone을 이용해 자연스럽게 리깅했습니다.

03

Wing

웨이트를 자연스럽게 줘서 리깅했습니다.

04

Breast

나중에 언리얼에서 사용할 컨트롤러를 만든 후, 스킨을 줬습니다. 이후에 언리얼에서 Spring Controller를 적용했습니다.
